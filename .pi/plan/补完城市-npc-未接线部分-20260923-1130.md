## 目标

把已经写好、但还没接上的城市 NPC 能力做完：远程皮肤、粗细手臂、装备与库存、摊位交易、对话框/编辑器背景、可视化编辑，以及 `/exworld npc edit <id>`。不复制 Easy NPC 源码，不增加运行时依赖。第 7 节序列节点规格仍是占位，这次不发明节点类型，也不做序列蓝图编辑器。

## 现状

- `NpcLoadout`、`SkinUrls`、`NpcRemoteSkins` 已在，但渲染仍走 `UrbanNpc.clientTexture()`，且固定宽模型。
- `UrbanNpc.applyLoadout` / `restock` / `notifyTrade` 已写，`NpcRuntime.sync` 仍只设贴图字符串并调用 `NpcSystem.offers`，库存和装备不会生效。
- `clearEquipment()` 和无参 `dropEquipment()` 在 1.21.1 上很可能编不过；未使用的 `Villager` 导入一并删掉。
- 右键在 `tradingOpen` 时就开交易，走路去摊位途中也会开。
- `UrbanDialogScreen` 没有空的 `renderBackground`；`NpcEditorScreen` 仍调用原版背景。身份页解析了 `f6`，但 `fill()` 不回填 `doc.loadout().format()`。
- `/exworld npc edit` 仍是视线选取，没有 `<id>`。
- 编辑器是九页表单，没有拖拽节点和吸附连线。

## 行为

1. **同步**：文档版本变化时调用 `applyLoadout`（设置 `skinKind`/`slim`、六槽装备、空库存才灌入初始库存、按库存生成报价）。每个 tick 再调用 `restock`，由它自己用 `nextRestock` 节流。不要在每次保存时清空已成交的库存。
2. **外观**：渲染器用 `NpcRemoteSkins.resolve(textureId, skinKind)`。`resource` 走资源路径，`player` / `player:` 走 Mojang 再下载，`url` 与 `http(s)` 直接下载。失败、非法尺寸、`file:`、回环和私网主机都回退 Steve。宽/细两套 `PlayerModel`，按 `entity.slim()` 切换。加上盔甲层和手持物品层。`slim` 只跟文档字段走，不从 Mojang metadata 自动改文档。
3. **交易**：当前行动是 `trade`，且 NPC 已进入该行动地点半径（地点取行动参数 `place`，否则时间节点地点，再否则家）时才允许交易。否则右键打开对话；有 `closed` 对话时用它。对话按钮里的交易行动同样检查“在摊位”。
4. **死亡掉落**：覆盖 1.21.1 的 `dropEquipment(ServerLevel)`（若编译器给出的签名是 `dropCustomDeathLoot`，以编译错误为准，只改这一处）。先掉已穿装备（默认掉落率为 0 时手动掉六槽），再掉剩余库存并清空库存。不要调用不存在的 `clearEquipment()`，改成把六槽设为 `ItemStack.EMPTY`。
5. **界面**：`UrbanDialogScreen` 与 `NpcEditorScreen` 覆盖 `renderBackground` 为空方法，不调用 `super`。需要压暗时在 `render` 里自己画半透明矩形。
6. **编辑器**：身份页回填 loadout 字符串，提示改为 `slim/kind/restock/equip/stock`。时间、对话、关系三页加画布：
   - 时间：横条按 1440 分钟映射，拖动吸附 5 分钟，拖右缘改持续，右侧保留原属性框。
   - 对话：节点可拖（坐标只留在本次界面，不写入文档）；从按钮端口拖到另一节点并吸附，写入该按钮的 `dialogId`。
   - 关系：读取已下发的目录 id，从自身拖到目标 id 并吸附，写入 `toId`；类型、好感、备注仍在右侧。
   - 保存仍走现有服务端校验；失败保持草稿并显示错误。
7. **命令**：`/exworld npc edit <id>` 按文档 id 打开编辑器，权限仍为 2。去掉视线选取。
8. **不做**：不新增序列节点类型，不改 `NpcBrain` 里现有的 `sequence` 子行动遍历，行动页保持表单。

## 文件

- `src/main/java/net/exmo/exworld/npc/entity/UrbanNpc.java`：装备清空、掉落签名、到达判定辅助方法。
- `src/main/java/net/exmo/exworld/npc/entity/NpcRuntime.java`：`sync` 接 loadout/restock；`trade` 仅在到达后置 `trading`。
- `src/main/java/net/exmo/exworld/npc/NpcSystem.java`：交互和对话按钮共用“在摊位才交易”。
- `src/main/java/net/exmo/exworld/npc/NpcCommands.java`：`edit <id>`。
- `src/main/java/net/exmo/exworld/client/npc/UrbanNpcRenderer.java`：双模型、皮肤、盔甲、手持物。
- `src/main/java/net/exmo/exworld/client/npc/UrbanDialogScreen.java`、`NpcEditorScreen.java`：空背景；身份页回填。
- 新增 `src/main/java/net/exmo/exworld/client/npc/NpcCanvasEditor.java`：三页画布的绘制与拖拽，由编辑器转发鼠标事件。
- `src/test/java/net/exmo/exworld/npc/UrbanNpcLogicHarness.java`：补 `NpcLoadout` 往返，以及一个不启动 Minecraft 的 `SkinUrls` 断言（`file:`、localhost、用户信息拒绝；`https` 公网主机字符串通过 `reject()`）。
