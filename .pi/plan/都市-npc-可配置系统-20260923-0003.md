# 都市 NPC 可配置系统

在 ExWorld（NeoForge 1.21.1）新增独立的都市 NPC 子系统。参考 `res/BOs-Easy-NPC-1.20.1` 的数据驱动方式，不复制其源码，也不在运行时依赖该模组。行为、日程、路线、对话、关系和临时反应都由文档引用 id 组合，不写死成某一个 NPC 脚本。

## 参考什么，不搬什么

Easy NPC 只提供结构参考：

- 对话条目、按钮、优先级、界面选项（`DialogDataEntry`、`DialogOptionsData`）→ 本系统的 `DialogScript` 与可配置背景。
- 交互、交易、受伤、距离事件（`ActionEventType`）→ 传感器，而不是移植它的事件总线。
- 回家、闲逛、注视、恐慌、跟随（`ObjectiveType` 与 `MoveToPositionGoal`）→ 行动注册表和边际行为注册表。移动参数沿用速度、到达半径、超时后重试，而不是超时传送。
- 地面寻路（`NavigationType.GROUND`）和交易报价表 → 本系统的寻路模式与 `TradeSpec`。
- 它的关系枚举只覆盖主人/阵营条件，不够做人物关系网，因此单独做可编辑的有向关系图。

不移植：皮肤/姿势/装备编辑器、多加载器 Menu 包装、攻击与枪械目标、以及任何带版权头的源码。

接入方式对齐现有工程：实体登记学 `ExWorldContent`，客户端学 `ShipClient`，界面用 `Screen`（交易除外，走原版商人菜单），存档用 `SavedData`，网络在 `WorldNetwork.register` 里追加登记。编辑权限为 2 级；对话和交易对所有玩家开放。

## 数据与运行时

逻辑 NPC 是一份可编辑文档，实体只保存文档 id 和运行时状态。改文档后，引用它的实体在下一拍重新装载。关系图与文档放在同一份世界存档 `exworld_urban_npcs`，实体重载后关系仍在。

`NpcDocument` 字段：

- 身份：`id`、显示名、可选贴图（默认原版 Steve）。
- 地点：`NpcPlace`（id、坐标、维度、朝向、半径）。家是其中一个地点引用。
- 路线：`NpcRoute`。模式为 `PATHFIND`（路点是目的地，用地面寻路）或 `MANUAL`（按折线逐点移动，不改写路点）。可循环、可调速度。
- 行动：`ActionSpec`（id、类型、参数、组合时的子行动 id 列表）。
- 时间线：`TimelineNode`（开始分钟 0–1439、持续分钟、绑定行动 id、可选地点、优先级）。窗口可跨午夜。
- 对话：`DialogScript`。模式 `FIXED` 或 `AI`；固定台词、按钮、背景、AI 提示词、失败回退句。
- 边际：`MarginalBinding`（行为 id、启用、优先级、半径、持续 tick、参数）。
- 交易：`TradeSpec`（付出物品、获得物品、数量、最大次数）。
- AI 设置：注视距离、家附近闲逛半径、地面寻路、互动过滤器（玩家、其他 NPC、门、工作方块）。

关系边：`fromId`、`toId`、类型字符串、好感 -100 到 100、备注。类型不写死枚举，编辑器提供常用值（家人、朋友、同事、对手、雇主）并允许自定义。

实体运行时：当前节点、路线下标、卡住计数、边际行为 id 与结束 tick、被打断前要恢复的节点、对话是否占用。缺文档、缺地点、缺行动时进入安全闲置并记一次日志，不抛到实体 tick 外。

首次创建存档时写入一份**数据预设**（摊贩：家、来回路线、白天交易节点、固定对话、一条关系、启用“看见打架就逃”）。引擎不按这个 id 写特殊分支，预设可在 GUI 里改或删。

## 行为组合

决策放在不依赖实体类的 `NpcBrain`，便于纯 Java 测试。世界 tick 只把传感器事实传进去，再执行返回的决定。

每拍顺序：

1. 整拍包在捕获里。任何异常都清成闲置并记日志，不让 NPC 卡死服务器。
2. 传感器：附近有人战斗、被玩家或其他实体挡住、受伤、被推出拴绳、看见已登记关系、寻路失败或手动路点不可达。目标缺失、区块未加载、实体已移除都返回“未触发”，不产生空指针。
3. 已启用且优先级更高的边际行为可挂起当前日程，记下恢复节点和到期时间。到期或条件消失后回到原节点，不重头随机选一个。
4. 否则按当日时间选节点：分钟 = `(dayTime % 24000) * 1449 / 24000` 修正为 0–1439。候选是 `开始 <= 当前 < 开始+持续`（跨午夜则分段判断）。同刻取优先级高者，再取开始更晚者。没有节点时回家或按 AI 设置闲逛。
5. 节点绑定的行动可以是组合行动。子行动按序执行；未知 id 跳过该子项并继续。

内置行动（注册表可再登记，文档只存 id）：

- `idle`、`look_around`、`interact_nearby`（按过滤器看、打招呼、开关门或面对工作方块）
- `hold_post`（到指定地点后站住并保持朝向）
- `follow_route`、`go_home`、`wait`
- `trade`（站到摊位；只有该节点生效时右键才开商人界面，否则走“未营业”对话）
- `speak`（固定一句或打开对话）
- `sequence`（按子 id 组合以上行动）

移动：

- `PATHFIND` 使用 `GroundPathNavigation`。失败累加卡住计数，到阈值后触发让路或等待，然后重新寻路。不在超时时传送。
- `MANUAL` 朝下一精确路点移动。被挡住时侧向一小步；仍挡住则等待，不改路线、不崩溃。到达后推进下标，循环路线回到起点。
- 对话打开时暂停移动。关闭后从挂起的节点继续。

内置边际行为（除逃跑示例外，并可扩展）：

- `flee_combat`：半径内看见战斗，离开现场，优先跑向家。
- `yield`：被玩家或其他 NPC 挡住、推动时让开，然后恢复路线或占岗。
- `watch`：看见附近互动时转身注视，不离开岗位。
- `greet_known`：看见关系图中的 NPC 时短暂停下并面向对方。好感低于阈值则不打招呼。
- `return_leash`：被带离家或岗位超过半径时寻路回去。
- `hide_hurt`：受到伤害后短时后退或蹲伏。
- `call_help`：受伤时通知半径内、关系为盟友且已启用该行为的 NPC，让它们看向伤害来源。
- `resume`：显式恢复被打断的日程。到期时也会自动恢复。

未知边际 id 在保存时被服务器拒绝并回错误信息；读旧档时未知 id 被忽略，NPC 继续执行其余行为。

## 对话与交易

玩家右键 NPC：若当前节点行动是 `trade`，打开原版商人菜单，报价来自文档。否则打开都市对话界面。

对话界面是客户端 `Screen`，不使用容器：

- 面板自底部滑入，约 8 tick 缓出。
- 台词打字机显示，速度可在脚本里设。
- 选项按钮在正文后依次淡入。
- 背景可设 ARGB、透明度、可选贴图；无贴图时用深色玻璃面板。关闭键和 Esc 可关。

`FIXED` 直接显示台词与按钮。按钮可绑定另一个对话 id，或一个行动 id（例如打开交易）。`AI` 把 NPC 名、当前节点、关系摘要、玩家名和最近几句发给提供器。服务端用 `CompletableFuture`，不阻塞世界 tick。界面先显示思考动画。超时、未配置或请求失败时使用该脚本的回退句。不把密钥或配置写进客户端包。

提供器接口 `DialogModel`：内置 `fixed` 与 `http`。服务器配置增加 URL、模型名、超时毫秒和可选密钥。未配置 URL 时 AI 模式等价于回退句，游戏仍可玩。

## 编辑工具

创造物品 `exworld:npc_wand`（都市 NPC 编辑杖）。

- 右键 NPC：打开该文档的编辑界面。
- 潜行右键：在“选择 / 设家 / 追加路点 / 设占岗点”之间切换，动作条显示当前模式。
- 对准方块右键：按当前模式写入家、路点或地点。路点顺序可在界面里上移、下移、删除。

命令挂在现有 `/exworld` 下：

- `npc create <id>`、`npc spawn <id>`、`npc edit`（看向 NPC 或手持编辑杖）、`npc list`。

编辑界面一个屏幕、九个分页，服务端校验后整份替换文档：身份、地点、路线、时间线、行动、对话、关系、AI、边际行为。列表用按钮切换，字段用输入框和下拉，不把主编辑做成一整块 JSON。保存失败时界面保留草稿并显示服务器返回的错误。

## 验证

`UrbanNpcLogicHarness` 覆盖：

- 时间线选择，含跨午夜、优先级和空节点回退。
- 缺行动、缺地点、未知 id 不抛异常，并落到闲置或下一项。
- 边际行为抢占日程，到期后恢复原节点。
- 关系查询对缺失 NPC 返回空，不抛异常。
- 手动路线推进与循环；寻路失败计数触发让路而不是异常。
- 固定对话返回台词；AI 失败返回回退句。
- 文档与关系边编码往返。

实现后运行 `gradlew urbanNpcLogicTest` 和 `gradlew compileJava`。游戏内再确认：生成预设 NPC、用编辑杖改家和路点、改时间节点、固定对话动画与背景、交易只在节点内打开、挡住路线不报错、附近战斗触发逃跑后回到原日程。
