# 客户端接入 WebView2 窗口

在 ExWorld（NeoForge 1.21.1）客户端加一个 Windows 专用的 Edge WebView2 窗口。游戏逻辑仍走现有 Java GUI；WebView2 只作为可开关的独立窗口，供以后用 HTML 做界面。

## 范围

做：

- 仅 `Dist.CLIENT` 且仅 Windows x64。其它平台或未安装 WebView2 Runtime 时，游戏照常启动，聊天栏提示一次。
- 一个置顶的独立窗口，父窗口设为 Minecraft 的 GLFW HWND（owned window，不是 `WS_CHILD`）。不把网页画进 OpenGL 画面，也不改 `SequenceScreen` 等现有界面。
- 默认按 `F8` 打开，也可执行客户端指令 `/exworld webview`。再次打开只把已有窗口拉到前台，不新建第二个。
- 首次打开内置页 `assets/exworld/webview/index.html`（用 `NavigateToString` 读资源，不走 `file://`）。页内可以调用 `window.exworld.post(json)`，Java 侧收到消息。
- 关闭：窗口关闭按钮、页面里的关闭、或退出世界 / 客户端停止时关掉，并恢复鼠标抓取。

不做：

- 不把 WebView2 合成进 `GuiGraphics`（需要 D3D 共享纹理，这一轮不碰）。
- 不替换序列界面、地图或日志。
- 不自动下载 WebView2 Runtime，只使用系统已安装的 Evergreen Runtime。
- 不开放任意本地文件或 `javascript:` URL。

## 实现

COM 调用放在专用 STA 线程上，客户端线程只投递请求。

1. Gradle 增加 `net.java.dev.jna:jna`（仅客户端代码引用）。增加任务从官方 NuGet `Microsoft.Web.WebView2` 取出 `runtimes/win-x64/native/WebView2Loader.dll`，打进模组 `natives/windows-x64/`。运行时解压到 `游戏目录/exworld/natives/` 再加载。用户数据目录用 `游戏目录/exworld/webview2`。
2. 新建客户端包 `net.exmo.exworld.client.webview`：
   - `WebView2Window`：`open()` / `close()` / `post(String)`，线程安全，单窗口。
   - `WebView2Host`：STA 线程、`CreateWindowExW`、消息循环、`CreateCoreWebView2EnvironmentWithOptions`、`CreateCoreWebView2Controller`、`NavigateToString`、`add_WebMessageReceived`。
   - `WebView2Com`：只声明用到的 JNA COM 接口和回调，不包整份 SDK。
   - `WebView2Client`：注册按键与 `RegisterClientCommandsEvent` 的 `/exworld webview`。打开时若没有 Screen，则 `mouseHandler.releaseMouse()`。
3. 在 `Exworld` 构造函数的 `Dist.CLIENT` 分支调用 `WebView2Client.register(modBus)`。服务端类不引用这些类型。
4. 内置页只显示标题和「桥接正常 / 关闭」按钮，用来确认窗口和 `postMessage`。中英语言键补按键名和失败提示（缺 Runtime、非 Windows、创建失败）。

DLL 是可选的微软可再发行组件，运行时动态加载，不链进 GPL 源码。缺少 DLL 或 Runtime 时功能不可用，模组其它部分不受影响。

## 验证

- 纯 Java 测试：请求队列在非 Windows 上是 no-op；内置 HTML 能从 classpath 读出；拒绝 `file:` 和 `javascript:`。
- 手动：Windows 上 `runClient`，按 F8 或 `/exworld webview`，应出现 Edge 内核窗口并显示内置页。点关闭后窗口消失、鼠标回到游戏。卸掉或假装缺少 Runtime 时，只提示、不崩溃。
- 服务端 `runServer` 不加载 WebView2 类。
