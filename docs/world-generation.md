# 世界生成契约

ExWorld 世界从一个 128×128 的初始战略窗口开始；每个世界格默认对应 4×4 个 Minecraft 原生区块。玩家抵达窗口外时，服务端会按需新增并持久化未配置的单格区域，直到 Minecraft 最大世界边界。M 地图每次只传输玩家附近的 128×128 视图窗口。新世界默认开启**手动设置区域组**：每个世界格先独立成为一个区块组，获授权玩家可在 GUI 中合并、拆分、命名、设置据点和资源、添加内置／ASCII 图标，并控制是否显示在 M 地图上。关闭手动设置后才会按群系斑块和据点自动生成区块组；区块组可以是 L 形、凹多边形或曲折长条，不要求规则正方形。

## 生成层

1. **群系斑块层**：草原、森林的扩张系数较大，沼泽、繁花原较小，因此会生成覆盖大量世界格的大草原和紧凑的小沼泽。
2. **区域组层**：手动模式中，获授权玩家保存的连通世界格集合决定边界、渲染剔除、地图图标和进入字幕。区域资料（名称、图标、据点、资源）属于整个区域组；只有已配置区域显示这些信息。自动模式中，每个连续群系斑块整体成为一个可玩区块组。
3. **地形适配层**：保留原版地形高度起伏，但按世界格群系重写区块群系容器、顶层/次表层方块和稀疏地表细节。当前支持大草原、森林、沼泽、沙漠、恶地、针叶林、高地和繁花原。
4. **据点组层**：默认放置 96 个稀疏地点；每个地点占用一个独立区块组，从自然斑块中切出，不再用建筑代替大部分自然地貌。
5. **群系地图色层**：大地图只使用每个世界格所属群系的固定 `mapColor`，不再采样周围地形、顶层方块或生成进度。客户端把 128×128 个群系色块上传为一张最近邻动态纹理，地图每帧只需一次主图 blit；快照使用紧凑的地图投影与 GZIP 压缩。

## 预生成与迁移

- 后台预生成属于每个世界存档的可选开关，默认关闭。它只覆盖初始 128×128 窗口；世界向外扩张后自动关闭，新增区域由原版视距加载流程按需生成。
- 按需生成可能以任意顺序发生，因此 SavedData 使用图幅内原生区块位图记录完成状态；后台队列读取这份进度，而战略地图不依赖地形生成状态。
- `/exworld world pregeneration` 查询状态；`/exworld world pregeneration on|off` 由 OP 开启或关闭。开启时队列每 Tick 至多补齐一个尚未生成的原生区块，重启后继续。
- 布局版本为 7；旧布局存档会重建区域/群系与生成进度，玩家锚点和绑定数据保留。
- ExWorld 通过 `DimensionType` Mixin 将原版主世界的真实存储高度改为 `0..319`：负 Y 区段不再创建，Y=0 是硬下界，并在新生成区块的该层铺设完整基岩。Nether、End 和不匹配原版主世界高度定义的自定义维度不会被修改。

## 区块组尺寸指令

- `/exworld world group_size`：查询当前世界的区块组边长。
- `/exworld world group_size set <1-16>`：将每个世界格设置为 N×N 个 Minecraft 原生区块，仅 OP 可用。
- M 地图右下角的“编辑区域组”可打开协作设置页；`world.allowClientGroupEditing` 默认开启，关闭后仅 OP 可以保存。左键／Shift+左键选择世界格；资料、据点/资源、组工具三个 Tab 会提示对应操作。保存时服务器要求当前窗口内所有世界格恰好归属于一个连通区块组，并以版本号阻止并发覆盖。
- 调整组尺寸时保留当前手动或自动分组，只重算每个世界格的物理坐标并重置预生成进度；锚点会根据物理坐标重新归属世界格。
- 1–16 的奇数和偶数尺寸都会严格对齐原生区块边缘。客户端视图窗口保持 128×128，不随比例改变；已持久化的世界格可继续向最大世界边界扩展。
