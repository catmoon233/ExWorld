# 默认地下城视角

普通探索使用固定高位地下城镜头，最大距离 12 格。系统鼠标解除中心锁定并保持可见，鼠标在屏幕上的位置会反投影成世界射线，玩家朝向射线命中位置；镜头自身不再被鼠标增量旋转。

## 当前行为

- 自动使用后置第三人称。
- 鼠标保持在普通可见模式，但 `MouseHandler` 内部仍维持游戏输入状态，因此世界点击、攻击和使用键不需要打开界面即可工作。
- 按住鼠标中键并拖动可旋转地下城观察方向（俯角限制在 28°–72°）；拖动期间暂停角色跟随光标，松开后恢复世界光标瞄准。
- 未打开 GUI 时，按住 Ctrl 并滚动滚轮，可在 3–24 格之间平滑调整地下城镜头距离；缩放后的镜头仍受当前区块组边界和原版墙体碰撞限制。地图界面的滚轮继续只缩放地图。
- 滚轮只修改目标距离，Tick 内指数趋近，渲染帧再用 partial tick 在前后状态间补帧。边界约束与玩家眼睛位置使用同一渲染时间基准，避免移动时的 20 Hz 距离跳动。
- 每 Tick 只由光标世界射线更新玩家朝向；镜头偏航与俯仰固定，避免原版第三人称、玩家旋转和自定义镜头三者互相回写造成颤动。
- WASD 相对独立镜头方向移动。
- 玩家朝向跟随世界光标；原版准星目标仍由后续交互系统接管，当前阶段保持原版攻击/使用输入。
- 镜头最大距离会在当前不规则区块组的灰白边界前动态收缩，且随后继续执行原版方块碰撞裁切，镜头不会越界或穿墙。
- 玩家与镜头之间的实心屋顶、墙体会形成平滑的视线通道；带方块实体的功能方块、门与梯子不会被剔除。
- 旁观、死亡或特殊玩法覆盖关闭地下城策略时恢复原版鼠标捕获。
- 当前包含自由鼠标，但不包含点击移动、战争迷雾或战斗锁定。

剔除只改变客户端分块模型，不改变碰撞、寻路、交互和服务端方块数据。玩家或镜头跨过整数方块时，仅将视线通道覆盖的少量区段标记为重建，避免每帧重建整个世界。

世界区段可见性同时支持原版 `SectionOcclusionGraph` 与 Sodium 0.8.x `OcclusionCuller`。Sodium 路径在可见性图遍历入口拒绝当前区块组外的 section，并在玩家跨过区块组边界时主动标记图更新；没有安装 Sodium 时专用 Mixin 会被跳过。

## 特殊玩法覆盖

后续战斗、剧情演出或载具模块不要直接操作 `Minecraft.options`，而应通过 `DungeonPerspective.setOverride(owner, profile)` 安装完整镜头策略，结束时调用 `clearOverride(owner)`。

覆盖按安装顺序生效，最后安装的策略优先。例如战斗模块可以提供动态第三人称策略，剧情模块可以临时提供 `CameraProfile.VANILLA`。模块结束后，视角自动回到普通探索的地下城视角。
