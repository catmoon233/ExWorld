# ADR 0009：运动学船体实体化，不做物理求解

## 状态

已接受。

## 决策

飞船以一条实体持有紧凑的船体结构（方块调色板 + 打包相对坐标）。管理员用飞船工具采集模板，并在可视化编辑器里划分部位与允许变体。运行时只做运动学平移/转向和轴向 AABB 拒绝，以及搭乘附着。

明确不做：质量、浮力、碰撞网格求解、红石网络、熔炉 tick、Create / Simulated 依赖、世界图旅行。

方块交互走白名单：门/活板门/栅栏门、箱子类容器、拉杆/按钮、工作台类菜单、舵机驾驶。按钮用实体自己的短延迟复位。

部位升级必须同时满足允许名单和占用掩码形状一致；成功后只替换该部位体素并增加修订号，客户端按修订号重绘。

## 原因

完整物理和每格 BlockEntity 会同时打 TPS 和 FPS。模板约束的部位升级保留外观自由度，同时避免玩家把任意世界结构做成飞船。

## 后果

- 船体上限 4096 方块；超过则采集失败。
- 同步先发 gzip 全量船体，之后只发局部方块变更。
- 拆解把方块和容器写回世界；目标被占用则拒绝。
