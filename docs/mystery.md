# ExWorld 解密活动运行手册

## 开一局

1. DM 站在列车汇合点执行 `/exworld story anchor`，设置 `lotm` 现有封印钥匙的目的地。
2. 在各线预定出生点执行 `/exworld mystery assign <玩家> PAST|FUTURE <characterId> <玩家可见名称>`。同一 `characterId` 可以分配给多位玩家；名称只显示“亚当”这类人物名。
3. 执行 `/exworld mystery start`。身份揭示后进入三分钟序章，然后过去线开始被追猎。`/exworld mystery status` 可查看阶段、轮次和封印数。
4. 结局后执行 `/exworld mystery lobby` 返回分配大厅，再执行 `start` 开下一局。大厅会清除上一局认知；局内 `rewind` 则保留线索与神父记忆。发布的蓝图仅在下一次 `start` 时进入运行快照。

玩家按 **U** 打开手记，按 **K** 跳过自己的镜头、字幕和报幕。其他玩家与服务端进度不受影响。断线重连会收到当前状态与仍在播放时间窗中的演出。

## 默认解谜链

- **过去**：与邪教徒交谈发现仪式 → 向神父之手检举 → 第一轮回结束后再次询问他 → 告诉他死亡地点 → 他每轮制作四份封印储备并交出仪式书。
- **未来**：工头提供每 20 秒一次的短工（每次 8 金币），或凑齐四名黑户；酒馆老板以 16 金币出售配方。掌握配方且神父已留下封印后，教会借出封印钥匙。教会警觉度达到 3 时暂不借出；警觉每分钟衰减 1。黑市以 12 金币出售一份额外封印碎片。
- **登车与结局**：未来者使用 `lotm:sealed_key` 回到已设的列车锚点，同 `characterId` 的在线过去者同行。所有在线存活者登车后，列车长残影出现在车头方向，时隙追影会追赶玩家。玩家有两分钟使用仪式书与列车长交谈以提前完成仪式；时间到时，仍有存活者持书也可完成。完成仪式后，封印数 `<8` 为坏结局、`8–11` 为普通结局、`≥12` 为完美结局；仪式书遗失则为坏结局。

任一过去者死亡会让全部同 `characterId` 的未来者持续受到凋零 II。过去线全灭后，待该效果结束或超时，服务端重置两线位置、道具、追猎者、NPC 状态、警觉和时间；线索与神父记忆保留。死亡者进入保持连接的世界视角回放界面，也可切换旁观或手记。

## 蓝图

`/exworld mystery blueprint exworld:<id>` 打开剧情与演出节点编辑器。编辑器支持节点搜索、拖动、带类型端口的连线、参数检查、撤销重做、断点与选中演出的单人预览。未完成蓝图可存草稿；发布时校验节点、端口、重复出边、不可达节点、循环、已注册的演出、物品、函数、枚举值及已分配身份。发布只改变下一局快照。

数据包示例位于 `src/main/resources/data/exworld/exworld_mystery/blueprints/passerby_suspicion.json`。图的执行由服务端负责；客户端只收到演出 ID、目标、`runId`、开始 tick 和时长。等待节点与已触发事件持久化。回溯生成新 `runId`，旧轮次的等待结果不能继续执行。

预录报幕以 `assets/exworld/sounds/mystery/<演出ID>.ogg` 提供，`sounds.json` 使用同 ID，字幕键为 `cue.exworld.mystery.<演出ID>.title` 和 `.subtitle`。缺少 OGG 时字幕照常显示。镜头只作短时插值，战斗镜头优先。

## 局内生前记忆

客户端从本轮出生起以每秒最多 10 次记录第一人称视角、维度、世界时间和附近实体的位置。压缩场景轨迹保存在客户端 exworld/mystery/memory/<runId>.xwr；不保存像素，不需要视频编码器，也不上传服务器。已授权的 Simple Voice Chat 接收语音写入 WAV，Minecraft 游戏音效事件写入 .sounds 并在回放中重新触发。死亡界面沿记录的视角在当前客户端世界里循环观看，保持服务器连接；下一轮开始时自动关闭，也可切换旁观与手记。磁盘空间不足或轨迹损坏时仍可使用旁观与手记。

ReForgedPlay 若已在录制，会在其完整世界封包 .mcpr 中写入 exworld.mystery.start:<runId> 与 exworld.mystery.end:<runId> 标记。该文件由 ReForgedPlay 在离开服务器后封存；其原生播放器会切换连接，适合局外查看。局内轨迹回放使用当前世界渲染，因此跨维度画面、已卸载的区块以及后来变化的方块或实体不能保证历史画面一致；完整历史世界状态以 .mcpr 为准。

同一客户端进程内断线时轨迹与语音暂停，重连同一轮次后继续；切换轮次或正常退出会封存原文件。游戏声音由音效事件重放，语音轨道记录本机收到的玩家语音；本机麦克风与其他系统音源不进入 WAV。Windows、Linux、macOS 的长时记录及含语音播放仍需各自实机验收。

## 验收建议

运行 ./gradlew mysteryRulesTest mysteryWorldReplayTest networkRegistrationTest jar lotmJar compileTestJava。在专用测试世界中分配至少一名过去者和两名同身份未来者，验证传导、死亡等待与回溯。检查局内镜头循环时连接保持、ReForgedPlay 的轮次标记、未完成草稿保存、错误蓝图发布失败、回溯后旧等待动作不执行、迟加入演出时间点和三个封印边界。最后分别在 Windows、Linux、macOS 测试长时轨迹记录、语音与低磁盘空间的旁观降级。
