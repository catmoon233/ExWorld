# 序列途径手册

序列系统在 `lotm` 附加模组里。游戏内切换序列的指令不变，`set` 和 `clear` 需要权限等级 2。`@s` 表示自己，换成玩家名即可指定别人。

```
/exworld sequence set @s <途径> <位阶>
/exworld sequence get
/exworld sequence clear @s
/exworld sequence pathways
/exworld sequence open
```

位阶填 `9` 到 `0`。旧日填 `old_one`，支柱填 `pillar`。也接受 `seq9`、`sequence_9` 这类写法。

主动技能不是聊天指令。晋升后进入法术轮盘施放。当前位阶会保留本途径更低位阶的属性、主动和被动，数值叠加。

除黄昏巨人、魔女外，其余途径目前只登记了序列九和序列八。填更高位阶会被拒绝。

**战士（序列九）**

- 属性：生命 +4，攻击 +1，护甲 +1，移速 +0.005，魔力 +20。
- 主动「战技·劈砍」：向前方短锥斩出一击，伤害随攻击力提升。冷却 4 秒。
- 被动「战斗直觉」：受击时获得短暂速度与抗性，并回复少量生命。冷却 8 秒。

**格斗家（序列八）**

- 属性：生命 +2，攻击 +1，攻速 +0.2，击退抗性 +0.15。
- 主动「格斗·连击」：贴身打出两段冲击，并击退目标。冷却 6 秒。
- 被动「近身压制」：攻击命中时使目标短暂缓慢。冷却 5 秒。

**武器大师（序列七）**

- 属性：生命 +4，攻击 +2，护甲韧性 +1，攻速 +0.1。
- 主动「武器·破阵」：宽弧斩开前方敌人，并短暂减速。冷却 8 秒。
- 被动「见招拆招」：受击时本次伤害降低 30%，并获得短暂伤害吸收。冷却 12 秒。

## 画家 `lotm:painter`

- 涂鸦者（序列九）：`/exworld sequence set @s lotm:painter 9`
- 记者（序列八）：`/exworld sequence set @s lotm:painter 8`

**涂鸦者（序列九）**

- 属性：幸运 +1。
- 主动「灵性涂鸦」：在准星处放置涂鸦陷阱，持续 25 秒。踩到的敌人减速 4 秒并发光。消耗 15 点法力，冷却 20 秒。
- 被动「色彩感知」：16 格内的刷怪笼、试炼刷怪笼和虫蚀方块会描边，并提示最近一处的方向。

**记者（序列八）**

- 主动「真实视野」：持续 15 秒。看穿隐身，并对你隐藏的形体显形。消耗 20 点法力，冷却 25 秒。
- 主动「迅捷」：获得速度 III，持续 20 秒。消耗 30 点法力，冷却 45 秒。
- 被动「记录者」：击杀生物时，45% 掉落额外经验，18% 掉落稀有战利品。

## 伟大母亲 `lotm:mother`

- 耕种者（序列九）：`/exworld sequence set @s lotm:mother 9`
- 医师（序列八）：`/exworld sequence set @s lotm:mother 8`

**耕种者（序列九）**

- 属性：生命 +2。

- 被动「药剂亲和」：所有药水效果持续时间 +20%。受到的治疗 +10%。

## 观众 `lotm:spectator`

- 观众（序列九）：`/exworld sequence set @s lotm:spectator 9`
- 读心者（序列八）：`/exworld sequence set @s lotm:spectator 8`

**观众（序列九）**

- 属性：幸运 +2。
- 主动「暗中引导」：对准生物施放。敌对目标会在 6 秒内把攻击随机转向附近其他生物；中立或友好目标会跟随你 20 秒。消耗 20 点法力，冷却 30 秒。
- 被动「敏锐观察」：击杀额外获得 10% 经验。附近生物头顶的粒子表示生命：绿为高，黄为中，红为低。

**读心者（序列八）**

- 属性：法术伤害 +5%。
- 主动「读心」：读取准星处生物的当前意图，并显示在聊天栏。对玩家则显示手持物品和主要正面效果。消耗 10 点法力，冷却 5 秒。
- 主动「思维模拟」（本阶进阶）：使目标在 6 秒内站到你这边，不再攻击你，并转而攻击附近的其他怪物。消耗 30 点法力，冷却 40 秒。
- 被动「读心直觉」：受击时有 8% 几率使攻击者虚弱 3 秒。

**祈光人（序列八）**

- 属性：护甲 +2。

- 被动「神圣亲和」：对亡灵伤害再 +15%（与勇气共鸣合计 +20%）。免疫凋零。

## 偷盗者 `lotm:thief`

- 偷盗者（序列九）：`/exworld sequence set @s lotm:thief 9`
- 诈骗师（序列八）：`/exworld sequence set @s lotm:thief 8`

**偷盗者（序列九）**

- 属性：攻击速度 +10%，移动速度 +0.05。原案的移速 +0.5 会把基础 0.1 拉到六倍，这里落成 +0.05。
- 主动「窃取之触」：对准 4.5 格内的生物。随机偷走快捷栏一件物品，或转移一个正面效果。对玩家偷物品有 35% 几率失败，只得到空瓶。消耗 15 点法力，冷却 20 秒。
- 被动「敏捷之手」：使用匕首或短剑时伤害 +10%。把武器加入 `lotm:short_blades` 标签即可生效。

**诈骗师（序列八）**

- 属性：幸运 +1。
- 主动「精神干扰」：对准 8 格内的目标，施加失明与移动混乱，持续 4 秒。目标受到伤害时，混乱立即解除。消耗 25 点法力，冷却 25 秒。
- 主动「思维误导」（本阶进阶）：在原地留下静止残影，持续 5 秒。残影被攻击后消失，攻击者减速 2 秒。消耗 20 点法力，冷却 30 秒。
- 被动「口才」：持续获得英雄之证的交易优惠。击杀经验 +5%。
