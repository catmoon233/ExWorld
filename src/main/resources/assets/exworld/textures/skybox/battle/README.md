# Battle skybox textures

Add six PNG files for each biome directory below. The names are fixed by the
corresponding `assets/fabricskyboxes/sky/exworld/battle/*.json` file:

`north.png`, `south.png`, `east.png`, `west.png`, `top.png`, `bottom.png`

Directories:

`prairie`, `forest`, `swamp`, `desert`, `badlands`, `taiga`, `highlands`, `flower_fields`
